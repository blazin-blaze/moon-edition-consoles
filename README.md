# Moon Edition for Consoles
Current Consoles Supported
- Xbox 360

Based on Cafeberry

# Installation (FAQs)
Please ensure the following things when installing:
- Your console language is set to English. If it is not, the game may crash.
- Any DLCs released after October 7th, 2014 (TU18) are uninstalled. If they are not, the game will crash.
- If you cannot move your camera when playing for the first time, check that your sensitivity settings have not been reverted to 0. If they have, change them back to 100.
- You have license patching enabled (in Dashlaunch). Without this enabled, you will be placed into an unplayable Demo Mode.
- You are not running the Peer Pressure exploit. This hack is confirmed not to work with Moon Edition.
